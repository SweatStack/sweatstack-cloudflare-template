# Icons

The runner icon (`icon.svg`, `logo.svg`, `badge.svg` and the PNGs rendered from them) is original
artwork made for this template, licensed with the rest of the repository (MIT).

Colours: background gradient #0D3A86 → #00205B (Norwegian flag blue), runner #EF2B2D (Norwegian flag red).

Replacing the icon in your fork? Edit the SVGs, then run
`npm i --no-save @resvg/resvg-js@2.6.2 && npm run icons` (see scripts/icons.mjs).
